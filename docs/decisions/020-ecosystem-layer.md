# 020 — Ecosystem Layer

**Status:** Accepted

---

## Proposal

إضافة `/ecosystem` كطبقة معمارية مسمّاة في مستودع Titan تجمع:
المعايير والقوالب الموجَّهة للمجتمع الخارجي الذي يبني حول Titan.

---

## Context

كان معيار الوصفات المجتمعية موثَّقاً في `docs/community/recipe-standard.md`.
هذا الموضع يقول للقارئ أن الوثيقة تشرح Titan — لكنها في الحقيقة لا تشرح
Titan بل تُعرِّف ما يبنيه المجتمع فوقه.

المشكلة الأعمق: لا يوجد في هيكل المستودع مكان يقول بوضوح
"هذا هو الباب الصحيح لمن يريد البناء حول Titan". الوثيقة وحدها لا تصنع
نظاماً بيئياً.

---

## Decision

### ١. طبقة `/ecosystem` في جذر المستودع

```
ecosystem/
├── README.md                   ← نقطة الدخول للمساهمين الخارجيين
└── recipes/
    ├── STANDARD.md             ← معيار الوصفات المجتمعية
    └── template/               ← نقطة بداية جاهزة
        ├── pyproject.toml
        ├── recipe.py
        └── RECIPE.md
```

### ٢. الحدود الصارمة

- **لا كود Core:** `/ecosystem` لا يحتوي أي جزء من Titan Core، ولا يُستورد منه تلقائياً داخل `src/titan`. أدوات Python مستقلة (validators، scripts) مسموح بها — شرط أن تبقى خارج `src/titan` وألا يعلم بها Core.
- **لا تسجيل تلقائي:** Titan Core لا تعلم بوجود هذا المجلد ولا تستوردها.
- **لا CLI، لا registry، لا نظام تحميل:** المرحلة الأولى اتفاقيات وقوالب فقط.
- **لا إلزام بـ metadata:** `[tool.titan-recipe]` في القالب موثَّق كاختياري.

### ٣. نقل `docs/community/recipe-standard.md`

الوثيقة تنتقل إلى `ecosystem/recipes/STANDARD.md`.

السبب: `docs/` تشرح Titan للمطورين. معيار الوصفات المجتمعية ليس شرحاً لـ Titan
— هو الدستور الداخلي لطبقة Ecosystem. مكانه الطبيعي هنا.

### ٤. العلاقة بين الطبقات

```
Core  (src/titan/)      ← يُعرِّف ما هو متاح — صغير، مُجمَّد
  ↑ تستخدم فقط
Ecosystem  (/ecosystem) ← تُمكِّن البناء حول Core — اتفاقيات وقوالب
  ↑ يشرح
Docs  (/docs)           ← يشرح Core للمطور — مرجع وقرارات
```

---

## Rule

طبقة Ecosystem تُعرِّف الحدود وتُقدِّم القوالب — لا تُنفِّذ ولا تُسجِّل
ولا تُحمِّل أي شيء. أي شيء يجعلها مرئية لـ Core أو يُضيف سلوكاً تلقائياً
يتطلب ADR منفصلاً.

---

## Consequences

**ما يُكتسب:**
- مساهم خارجي يفتح المستودع يجد مساراً واضحاً للبناء.
- الفصل بين "ما يشرح Titan" و"ما يُمكِّن البناء حوله" أصبح مرئياً في
  هيكل المستودع نفسه.
- القوالب تُقلِّل الاحتكاك لأول وصفة مجتمعية.

**القيود المقبولة:**
- طبقة جديدة في جذر المستودع تُضيف مفهوماً يحتاج المطور الجديد أن يفهمه.
  `ecosystem/README.md` يحل هذا مباشرةً.

**ما يبقى خارج نطاق هذا القرار:**
- قائمة مجتمعية بالوصفات المعروفة — تنتظر وصفتين أو ثلاث فعلية.
- أدوات تحقق (linter، validator) — تُبنى عند الحاجة.
- إصدار مثال مرجعي كامل — مؤجَّل لما بعد ظهور وصفة مجتمعية حقيقية.
