# Titan Ecosystem

هذا المجلد هو باب الدخول لأي شخص يريد البناء **حول** Titan، لا داخله.

---

## ما هذه الطبقة؟

طبقة Ecosystem تُعرِّف الحدود والاتفاقيات التي تُمكِّن المجتمع من بناء وصفات
وأدوات تعمل مع Titan — دون أن تلمس Core ودون أن تحتاج موافقة مركزية.

Titan Core يبقى صغيراً ومستقلاً. Ecosystem هي الطبقة التي تجعل البناء حوله ممكناً.

---

## ما تجده هنا

```
ecosystem/
├── recipes/
│   ├── STANDARD.md     ← معيار الوصفات المجتمعية: التسمية، الهيكل، الحدود
│   └── template/       ← نقطة بداية جاهزة لإنشاء وصفة مجتمعية
├── extensions/
│   └── STANDARD.md     ← معيار الامتدادات المجتمعية (Extensions): التعريف، نقاط التكامل، الحدود
└── templates/
    └── STANDARD.md     ← معيار قوالب المشاريع المجتمعية (Project Templates): التسمية، الحدود، التوزيع
```

---

## ما تجده في مكان آخر

| ما تبحث عنه | مكانه |
|---|---|
| Core APIs والعقد الرسمي | `CONTRACT.md` |
| الوصفات الرسمية (كود) | `src/titan/recipes/` |
| توثيق الوصفات الرسمية | `docs/recipes/` |
| مرجع API كامل | `docs/reference/` |
| قرارات معمارية | `docs/decisions/` |

---

## في الأفق

هذه الطبقة في مرحلتها الأولى. أشياء قد تُضاف لاحقاً عند الحاجة:

- `examples/` — أمثلة مرجعية كاملة لوصفات مجتمعية
- `tools/` — أدوات تحقق اختيارية (linter، validator)
- `registry/` — قائمة مجتمعية بالوصفات المعروفة

لا شيء من هذا يُبنى قبل أن يكون هناك حاجة فعلية.
